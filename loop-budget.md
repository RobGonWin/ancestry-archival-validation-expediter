# Loop budget

- Autonomy level: `L1 / report-only`
- Objectives per run: `1`
- Bounded transforms per run: `1`
- Maximum attempts: `3`
- Same-error circuit breaker: `3 occurrences`
- Maximum changed files before human re-scope: `10`
- External writes: `0`
- Automated publication actions: `0`
- Context rule: include only records required for the next action; summarize
  prior attempts rather than replaying raw history.

An agent cannot raise these limits. A human must edit this file or approve a
new manifest.
