# Availability in this focused project

The commands below document the broader AAVE host integration. That CLI is not included in this extraction. Use an explicitly authorized host and a manually reviewed public cohort packet, or run these commands in AAVE. Do not assume an invocation adapter exists here.

# Agent handoffs

All hosts use the same context JSON, cohort IDs and review-table schema. Avoid copying entire conversation histories or private repository trees.

- Codex: `aave agent-context invoke --context <context.json> --provider codex --out <receipts>`.
- Cursor Agent: use `--provider cursor`. This invokes `agent`, not the Cursor editor's `cursor` launcher. Ask mode is read-only; host sandbox configuration remains in force. This installed version does not provide its OS sandbox on Windows. `--trust` acknowledges only the disposable folder generated by AAVE; command permissions are not bypassed.
- Claude Code: use `--provider claude`; Claude skill discovery also has a local pointer under `.claude/skills`.
- Cursor with Grok: first run `agent models` using your existing account. Supply an actually returned Grok identifier with `--provider cursor-grok --model <identifier>`. Catalog presence is not proof of inference or quota.
- Grok Bot: use `--provider grok-bot` to record a manual handoff. Give an authorized Bot the reviewed cohort JSON and `grok-bot-handoff.md`. The packet specifies disjoint researcher ownership followed by date/identity and skeptic review. There is no configured Bot API/CLI, automatic deployment or Bot messaging.

Invocation is a plan until `--execute` is supplied. Execute only after reviewing the generated public packet. The CLI uses a disposable working folder containing one cohort, no shell interpolation, bounded timeout, and a hash-keyed receipt. It does not grant OS isolation: local agent credentials, global configuration and host permissions still matter. Outputs are private advisory artifacts. Successful unchanged invocations are reused; failed runs retain their status and need an explicit retry.

Sources: [Codex non-interactive mode](https://learn.chatgpt.com/docs/non-interactive-mode), [Cursor parameters](https://cursor.com/docs/cli/reference/parameters), [Claude headless](https://code.claude.com/docs/en/headless), [Grok Bot](https://cursor.com/docs/grok-bot). Verify local CLI help before changing invocation flags. Never invent a model identifier or equate Grok Bot with Bugbot.
