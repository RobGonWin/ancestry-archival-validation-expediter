# Review AAVE contributions

Read `AGENTS.md`, `CONTRIBUTING.md`, and `loop-constraints.md`. Review the exact
proposed AAVE diff independently of its contributor and remain read-only.

1. Confirm the scope matches the stated archival, parser, documentation, or
   validation objective.
2. Verify contributed material is original or compatibly licensed and that
   public sources are cited rather than copied.
3. Verify fixtures are synthetic and cannot be linked to a person, family,
   account, or private evidence source.
4. Check offline format compatibility without bundling, reading, or logging a
   real export.
5. Require explicit provenance, uncertainty, limitations, and negative claim
   boundaries for derived assertions.
6. Test malformed, partial, duplicate, and contradictory input handling when
   relevant.
7. Run the project tests and strict public-release privacy audit.
8. Block unsupported identity, relationship, medical, cognitive, genetic, or
   causal conclusions.

Report findings without publishing, pushing, opening issues or pull requests,
or contacting any external project or program.
