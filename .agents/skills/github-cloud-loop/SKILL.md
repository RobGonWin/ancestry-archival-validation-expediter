# Review AAVE loop readiness

Operate at L1/report-only. Read `AGENTS.md`, `LOOP.md`,
`loop-constraints.md`, `STATE.md`, and `gate.yaml` before reporting.

Use only repository read/search capabilities and these Loop MCP tools:
`loop_list_patterns`, `loop_list_skills`, `loop_list_state_files`,
`loop_get_pattern`, `loop_get_skill`, `loop_get_state`,
`loop_recommend_pattern`, and `loop_estimate_cost`.

Report readiness gaps, evidence for each finding, and a bounded next action.
Do not edit files, update state, open issues or pull requests, publish, upload,
or merge. Never read or transmit real DNA exports, GEDCOMs, account material,
family evidence, recollections, living-person records, credentials, or local
vault content. AAVE compatibility is limited to user-owned exports processed
offline; this skill does not log in to or scrape Ancestry.com.

Stop if the requested review requires a write, private evidence, an external
call beyond the configured MCP server, or a privacy/licensing decision.
